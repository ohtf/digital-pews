# Unlisted presentations

Only reviewed presentation files belong here. The Pages assembler copies an explicit file list into a separate output directory after Zensical has built its site. Presentation pages are not part of the documentation navigation, search index, sitemap or old documentation redirects. The PCHT2026 deck has a `noindex, nofollow` tag. These are public files, not access-controlled content.

The maintainer approved publication of the current PCHT2026 draft on 20 November 2026. Its source is `pcht2026/`; its output route is `/digital-pews/pcht2026/`. Keep it unlinked from the site. Edit this tracked source for future published updates; local prep notes are not the deployment source.

The draft has ten main slides and one optional vertical slide under the timeline. It uses Reveal.js 6.0.1 and its notes plugin from jsDelivr. Arrow keys navigate; `S` opens the public-safe speaker notes. External dependencies mean this is not an offline bundle. AV acceptance and PDF/offline fallbacks remain separate preparation tasks.
